### Adding project screenshots

Screenshots are **manifest-driven** — no HTML editing required.

1. Drop the images into that project's folder, e.g. `assets/images/quicoo/`. Any filename,
   any format (`.jpg` / `.png` / `.webp`).
2. List the filenames in the `PROJECT_SCREENS` object at the top of `script.js`:

   ```js
   astroganga: ['1.webp', '2.webp', '3.webp'],
   ```

The work card slider, screen-count badge, arrow controls, dots, hero carousel slide and the
case-study modal gallery are all generated from that list. Leave a list empty and the project
keeps its branded placeholder tile, so the page never looks broken.

Optional captions:

```js
astrosane: [
  { file: 'screen-1.jpg', label: 'Services & Kundli Hub' },
],
```
